# Aura RNG

Ein alberner Glücks-Sammler für den Leif Game Hub: Würfle Auren, sammle alle 46 und finde den DERP-GOTT.

- 46 Auren in 10 Seltenheitsstufen, jede mit eigenem Effekt (alles im Code gezeichnet, keine Bilder)
- Wetter wechselt alle 4 Minuten, manche Auren tauchen nur bei bestimmtem Wetter auf
- Shop, Tränke, Erfolge, große Enthüllung für seltene Auren, Schlaf-Würfeln mit Auto-Würfler
- Speichert im Browser (localStorage), kein Backend

Statisch, kein Build nötig: `index.html` öffnen oder auf Cloudflare ausliefern.
